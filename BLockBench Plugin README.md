# Atomix Blockbench plugin
1. Open Blockbench, **File -> Plugins**, then **Load Plugin from File** and pick `atomix_tools.js`.
2. With a Bedrock Entity project open, use **File -> Export**: *Atomix: Check Names* and *Atomix: Export Pack File*.
Not needed to use the engine: plain Bedrock exports work without it. This only saves you mistakes and typing.
